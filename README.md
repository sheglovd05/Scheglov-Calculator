# Калькулятор на WPF

Настольное приложение для вычисления арифметических выражений.

**Автор:** Щеглов Даниил Никитич, группа ИПо-31
Пермский институт (филиал) РЭУ им. Г. В. Плеханова, отделение информационных технологий и программирования

## Возможности

- приоритет операций, скобки, унарный минус, возведение в степень;
- точные вычисления в типе `decimal` (0,1 + 0,2 = 0,3);
- предпросмотр результата по мере ввода;
- журнал вычислений с сохранением между запусками;
- тёмная и светлая темы, интерфейс на русском и английском языках;
- ввод с экранной и физической клавиатуры.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `0`–`9`, `.`, `+`, `-`, `*`, `/`, `^`, `(`, `)` | ввод символа |
| `Enter` | вычислить и записать в журнал |
| `Backspace` | удалить последний символ |
| `Delete` | очистить последнее число |
| `Esc` | очистить выражение |

## Как устроен разбор выражений

Дерево выражения строится методом рекурсивного спуска, приоритеты операций заданы
структурой методов разбора:

```
выражение  → слагаемое { ("+" | "-") слагаемое }
слагаемое  → множитель { ("*" | "/") множитель }
унарное    → "-" унарное | степень
степень    → первичное [ "^" унарное ]
первичное  → число | "(" выражение ")"
```
